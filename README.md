# 赵志伟 · 作品档案

个人主页 —— 一份以「印刷档案」为视觉语言的单页作品集，收录 **20 件作品图版**、
**47 条纪年**，以及从业、教学与研究方向的自述。

## 站点形态

整站是**一个自包含的 HTML 文件**（`index.html`）：

- CSS 与 JavaScript 全部内联，无构建步骤、无依赖安装
- 21 张作品图以内联 `data:image/jpeg;base64` 形式嵌入，无外部图片请求
- 动效库（GSAP / ScrollTrigger / Vanilla-Tilt）经 CDN 引入并带多源回退；
  **CDN 不可用时页面照常完整显示**，只失去动效
- 适配手机端：375 / 390 / 412 / 768 四档实测横向溢出为 0

## 本地查看

直接双击 `index.html` 即可，无需任何服务器。

## 部署

托管于 **Vercel**（Git 集成，push 即自动部署）。因为站点无构建步骤，配置为：

| 配置项 | 值 |
| --- | --- |
| Framework Preset | `Other` |
| Build Command | 留空 |
| Output Directory | 留空（直接托管仓库根目录） |
| Production Branch | `main` |

`vercel.json` 追加了两个响应头（`X-Content-Type-Options`、`Referrer-Policy`），
不需要时可直接删除该文件。

> 有意**不加** `X-Frame-Options`：它会让站点无法被 iframe 嵌入，而本地用于手机端
> 模拟预览的页面正是靠 iframe 加载本站。
